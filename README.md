# Smart Support Assistant API Documentation

## Overview
Documentation project for an AI-powered customer support assistant built using Zendesk APIs and Groq LLM integration.

## Features
- Ticket Management APIs
- User Management APIs
- Organization APIs
- AI-powered response generation
- Postman API collection
- Authentication documentation

## Technologies
- Zendesk API
- Groq LLM API
- Postman
- MkDocs
- Markdown
- REST API

## Documentation
Run:

mkdocs serve

## API Modules
- Authentication
- Tickets
- Users
- Organizations
- Search
- Views
- Macros
- Triggers
